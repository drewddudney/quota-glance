# Provider pet artwork

These images use the same authentic animation frames as the Mac app.

- Codex: original Codex desktop sprite cells, 192 × 208; idle and blink from row 0, four wave frames from row 3.
- Clawd: original Claude desktop animation frames, cropped to the shared 1200 × 800 viewport at (736, 1050), then scaled to 360 × 240 for the phone.
- Source details and provenance: `../../macOS/Resources/ProviderArtwork.md` in the public repository, or the sibling Mac project's `Resources/ProviderArtwork.md` in the local workspace.

No replacement mascots are drawn or generated.
